# Titans Forge Social Science Rubric

Use this rubric for scenario writing, agent proposals, advisor voices, ending logic, source notes, and public-facing historical explanations.

## Rules

- Zero Presentism: do not import modern moral or academic language into earlier periods. Explain what period actors believed and why.
- Use Real Sources First: prefer primary sources, official records, period memoirs, and high-quality historians. Give extra weight to sources close to the event. Useful historian models include Edward Channing, Douglas Southall Freeman, Marc Bloch, G.M. Trevelyan, Shelby Foote, and similar writers who treated history as disciplined social inquiry.
- Power Over Propaganda: explain incentives, political power, sectional interests, logistics, finance, food, elections, army survival, and institutional constraints.
- Proportionality: distinguish the existence of a controversy from its scale. Do not make a real grievance, exception, riot, or newspaper argument stand in for an entire society without evidence showing how widespread or decisive it was.
- Language Fidelity: use period-appropriate categories and terms where they clarify the decision.
- Complexity: show where competing sides or factions had real interests and where compromise or command consensus broke down.

## Agent Fields

Agent proposals should include these optional fields when relevant:

- `source_notes`
- `primary_sources`
- `historian_sources`
- `power_analysis`
- `complexity_note`

The local dashboard treats missing or weak rubric support as a quality warning, not a save-blocking error. A proposal can be technically valid and still require rubric review before approval.

## Current Source Notes

- Late-war Colored Troops stage: Lee headquarters letter to Lt. Gen. R.S. Ewell, March 27, 1865, signed by Charles Marshall. The useful point for game language is that Lee objected to "Colored Troops" mainly because it was the enemy's designation, but accepted "colored," "Confederate troops," or "volunteers" if the men preferred it, while stressing voluntary service, respectful treatment, and soldierly obligations.
